TROUBLESHOOTING
===============================================================================

Error: "ModuleNotFoundError: No module named '...'"
→ Solution: Reinstall packages
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt

Error: Permission Denied
→ Solution: Run PowerShell as Administrator or use full path to python

Error: Port already in use (for dashboard)
→ Solution: Kill process using port 8501 or specify different port
   .\.venv\Scripts\python.exe -m streamlit run deployment/dashboard.py --server.port 8502
